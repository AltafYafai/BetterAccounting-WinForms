# Security Policy

## Supported Versions

We actively maintain security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue in BetterAccounting, please report it responsibly.

### How to Report

**Do not open a public issue for security vulnerabilities.**

Instead, please report them via:
1. **Email**: security@betteraccounting.app (if valid)
2. **GitHub Private Report**: Use GitHub's security advisory feature

### What to Include

When reporting a vulnerability, please include:
- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Suggested mitigation (if known)
- Your contact information (for follow-up)

### Response Timeline

We aim to respond within:
- **24 hours** for critical vulnerabilities
- **72 hours** for high/medium vulnerabilities
- **7 days** for low vulnerabilities

## Disclosure Policy

1. Developer acknowledges receipt
2. Investigation and verification
3. Development of fix (if applicable)
4. Coordinated release of fix and announcement
5. Credit to reporter (unless anonymity requested)

## Data Protection

This application stores all data locally. We do not:
- Collect personal data
- Transmit data externally
- Store passwords or credentials

All financial data remains on the user's device. Ensure proper backup procedures are in place.
